<h1 align="center">Bedrock UI Installer</h1>

<p align="center">
  <b>Android companion app for the <a href="../../../BedrockUI">Bedrock UI</a> mod.</b><br>
  It exports the files the mod needs from <b>your own</b> Minecraft: Bedrock Edition and installs the mod into your
  Java launcher.
</p>

<p align="center">
  <b>Latest version: 1.3.2</b> · <a href="../../releases">Download the APK</a> · License: MIT
</p>

> [!IMPORTANT]
> **You need your own, official copy of Minecraft: Bedrock Edition** on the same phone. This app contains **no**
> Mojang files and **no** copy of the mod: it reads Bedrock from your phone and you import the mod jar yourself, so the
> mod's credits and license stay with the mod.

## What it does

Bedrock UI makes Minecraft: Java Edition look like Minecraft: Bedrock Edition by reading Bedrock's own UI files. On a
PC it finds them in the Bedrock install, but Java launchers on Android (Zalith Launcher and others) can't read another
app's files. This app bridges that gap:

1. It checks that Minecraft: Bedrock Edition is installed **from an official store** (Google Play, Amazon, Samsung,
   Huawei or Xiaomi).
2. You import the Bedrock UI mod jar you downloaded from the [mod's Releases](../../../BedrockUI/releases). The app
   checks that it really is Bedrock UI.
3. It copies only the parts of Bedrock the mod reads (UI layouts, UI and item textures, fonts and texts) into
   `bedrock_data.zip`.
4. It installs the mod jar and `bedrock_data.zip` into your launcher's game folder, or saves `bedrock_data.zip` to
   Download so you can import it yourself.

The app is in English, Bahasa Indonesia, 中文, Tiếng Việt, Filipino and 日本語, and shows a copyright notice before
anything is exported.

## Requirements

| | |
|---|---|
| Android | 7.0 or newer |
| Minecraft: Bedrock Edition | Installed from an official store |
| Bedrock UI mod | `BedrockUi-mc26.2-<version>-release.jar` or `BedrockUi-mc26.1.2-<version>-release.jar` from the [mod's Releases](../../../BedrockUI/releases) |
| A Java launcher | For example Zalith Launcher, with a Fabric version and Fabric API |

The app asks for no permissions: it only uses the folders and files you pick yourself.

## How to use

1. Install `bedrock-ui-installer-<version>.apk` from the [Releases](../../releases). Android may warn that the app is
   from an unknown developer, because it is not on Google Play.
2. Open the app, read and accept the copyright notice.
3. Tap **Import mod file (.jar)** and pick the Bedrock UI jar.
4. When both requirements show a tick:
   - **Install to game folder...**: pick your launcher's game folder (the one with `mods`). The app copies the jar
     into `mods` and writes `bedrock_data.zip` next to it.
   - **Save only bedrock_data.zip**: saves the zip to Download. Use this when your launcher's folder can't be picked,
     then import the jar and the zip in your launcher.
5. Start the game. The mod unpacks `bedrock_data.zip` on first start.

Using **Zalith Launcher**? Follow the illustrated guide in the mod repository:
[docs/install-zalith](../../../BedrockUI/blob/main/docs/install-zalith/README.md).

> [!WARNING]
> `bedrock_data.zip` contains files from Minecraft: Bedrock Edition. Keep it on your own devices and **never share or
> upload it**.

## Troubleshooting

- **"Minecraft Bedrock is not installed"** or **"... was not installed from an official store"**: install Bedrock
  from an official store. If yours is official, tap **Copy log** and open an issue with it.
- **"This file is not the Bedrock UI mod"**: pick the `-release.jar` from the mod's Releases, not another mod or a
  `-sources.jar`.
- **You updated Bedrock**: export `bedrock_data.zip` again and replace the old one; the mod unpacks the new one
  automatically.


## Building from source

No Gradle: the APK is built with the plain Android SDK tools. You need the Android SDK (build-tools 36, platform 36),
JDK 21 and Python. From Git Bash (Windows) or a Linux/macOS shell:

```sh
export ANDROID_HOME=~/Android/Sdk JAVA_HOME=/path/to/jdk-21
export BEDROCKUI_KS_PASS=<your keystore password>
./build.sh                   # -> bedrock-ui-installer-<version>.apk
```

- The version is `android:versionName` / `android:versionCode` in `AndroidManifest.xml`; raise both for an update.
- `build.sh` creates `keystore.jks` on the first run. **Keep it safe and never upload it**: updates must be signed with
  the same key, or Android refuses to install them over the old app.
- The texts for all six languages are generated by `strings.py` into `res/values*/strings.xml`.

| Path | Contents |
|---|---|
| `src/dev/bedrockui/exporter/MainActivity.java` | The app screen: requirements, official-store check, mod import, install / save |
| `src/dev/bedrockui/exporter/Exporter.java` | Picks the needed files out of the Bedrock APK and writes `bedrock_data.zip` |
| `res/` | Icon and texts (6 languages) |
| `strings.py` | Source of all texts |
| `build.sh` | Builds and signs the APK |
